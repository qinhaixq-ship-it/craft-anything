# Craft Anything · 万物可造

一个纯前端的手作者作品画廊。泥、木、线、纸、金属，或者一行代码——做出来了就值得被看见。

## 特性

- **瀑布流画廊**：卡片按作品比例自然排布，响应式 1 / 2 / 3 列
- **分类与搜索**：按门类筛选，按作品名 / 作者 / 标签 / 描述全文搜索
- **作品详情**：大图、材料工具、创作时间、作者自述
- **上传作品**：拖拽或点选图片，浏览器端自动压缩到 1280px 再存储
- **喜欢**：本地记录，卡片与详情页同步
- **备份**：一键导出 / 导入 JSON，换设备不丢数据

## 数据存储

所有作品与喜欢都存在浏览器的 `localStorage`（键名 `craft-anything.v1`）中，
不上传服务器、不依赖后端。清除浏览器数据会丢失内容，请先用「导出」备份。

## 本地运行

直接用浏览器打开 `index.html` 即可；或起一个静态服务器：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 部署

已通过 GitHub Pages 发布，`main` 分支根目录即站点。

## 结构

```
index.html   页面结构
styles.css   样式（暖纸质风格，衬线标题 + 无衬线正文）
app.js       渲染、筛选、上传、存储逻辑（无依赖）
```
